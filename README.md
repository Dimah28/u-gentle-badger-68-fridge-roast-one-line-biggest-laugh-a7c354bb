The entry:

> My fridge beeps when the door stays open too long, like it pays the electricity bill — meanwhile it runs a lightbulb 24/7 for nobody.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` as UTF-8 with no extra bytes. The same bytes are
written on every run. Python 3.13, standard library only, no network.
