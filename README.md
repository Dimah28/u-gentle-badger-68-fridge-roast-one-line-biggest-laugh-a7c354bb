The entry:

> My smart fridge emails me a weekly report: 47 door opens, zero vegetables eaten — and a passive-aggressive salad recipe I will also ignore.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` as UTF-8 with no extra bytes. The same bytes are
written on every run. Python 3.13, standard library only, no network.
